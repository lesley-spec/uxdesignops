Define — frame the problem, not the feature

One-pager + UX epic, after anti-sycophancy and dual marketplace lenses.

design-thinking-ux (master) write-spec anti-sycophancy brand-operator-ux-persona creator-affiliate-ux-persona design-system

Framing (labeled)

  • Verified: Last-click hides AI-visible publishers (churn risk). Path store only has affiliate-click journeys. Telemetry v1 cannot claim attribution. Index ≠ transaction attribution. Compensation must be additive.
  • AI interpretation: The job is a documented partner decision from an explainable index — optimize, bonus test, or measure more — not “see the Wired path.”
  • Goal (not a feature): A Brand operator can name which partners have enough AI-influence evidence to act on, and can simulate an additive monthly bonus, without treating modeled conversions as attributed.

Pressure test

  • Shipping more reports is not the goal. Yifei: storytelling before crediting.
  • Partner payout UI / publisher report is later — advertiser is the decision-maker.
  • Path insertion as co-equal to the index would overclaim. Telemetry shaping forbids it in v1.
  • “Low influence” must not be used when the issue is missing data — use Insufficient evidence.

  • Confluence: test plan draft · Jira UX-648
  • Maze 20–40 for Index + bonus tasks; Outset 5–8 if Path vs Index confusion shows up. Do not recruit.
  • Tasks: find observed vs inferred; name bonus-eligible vs insufficient evidence; say the bonus is simulated; treat Path as future.
  • No Maze/Outset API in this harness — Confluence + Jira are the published artifacts.

A11y pre-flight (synthetic)

  • Secondary nav is buttons with aria-current. Partner names in the table are buttons.
  • Skip link to report. Focus-visible on nav and row buttons. Tables have headers.
  • Observed / Inferred / Insufficient are text chips, not color alone.
  • This is not a conformance audit. Remaining: methodology is a details disclosure (keyboard OK); Path page must not look like a live conversion report in Maze.
