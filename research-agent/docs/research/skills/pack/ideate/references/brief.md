# Ideation brief notes

## Framing quality

| Level | Meaning |
|---|---|
| **Strong** | One-pager and/or detailed PRD present; epic optional |
| **Partial** | Epic/tickets or short one-pager; some success criteria missing |
| **Thin** | Granola/meeting notes or chat only — snapshot + gaps required |

Thin intake is allowed. Warn once; diverge if designer overrides.

## Brief must include

- Problem / opportunity (from sources — Verified where possible)
- Audience + JTBD
- Constraints and **non-goals**
- Success criteria snippets (or “missing — using notes proxy”)
- Evidence anchors (links), not new research claims

## Directions

Default **3–5**. Each direction: name, concept (2–4 sentences), which framing items it addresses, main risk. Prefer divergent axes (IA, density, Brand vs Partner emphasis) over cosmetic variants unless designer asked for visual variations only.
