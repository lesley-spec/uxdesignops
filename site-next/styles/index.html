Design tokens

Design tokens are the building blocks of the UI. These pages list the living set: every design token, every VNext primitive, and every screen-size token. The same names are used in Figma and on this site.

  • A token is a name that points at a color, a type style, or a measurement.
  • Bind the token. Do not type the value by hand.
  • The name says where it is used. color/text/text-default is the default text color.
  • VNext Light and VNext Dark share the name. The value changes with the mode.

What a token is

Two things. A name, and the value that name points at. The name stays when the value changes, so a screen and this page can share one decision.

Name color/text/text-default
Value, VNext Light

Figma binds the variable. This site uses the same name. A hex typed into a frame will not follow the next change.

Parts of a name

Names go from the general to the specific. The pieces are separated by slashes.

  1. colorWhat it is
  2. textThe role
  3. text-defaultThe decision

Read it as a sentence: the default color for text.

How to use one

In Figma, bind the variable or apply the text style. On a product screen, clone an example and place a real component. A primary action is the Primary Button, State Default. A field label is the Field Label text style.

To check a color, open Color and search the name. The swatch is the current value. Bind the name.
