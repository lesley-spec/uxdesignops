Agents

UX researcher

Answers a question from what impact.com already knows, then plans only the study that is still missing.

Ready

Get started

Install once, then paste this.

When the gate is “problem worth solving,” the next door is design thinking at Define. It does not start ideating on its own.

Overview

Call ux-research. It reads one skill at a time. It checks the Frame before it plans fieldwork, and it stops before it launches a study or writes tickets. Name a single skill if you only want that job.

Usage

Use it when

Someone has a research request, a “what do we know?” question, or a finding that needs a closer look.

Use another door when

The output should be a screen. That is the designer, after the problem is confirmed. A full Empathize-to-Test project is design thinking.

Anatomy

1

Route

research-intake sorts the ask. Some requests close here.

2

What we know

user-context and user-personas against the Frame.

3

Evidence

data-analyze, research-synthesis, or synthesize-research, depending on the source.

4

A study, if needed

research-planner and research-builder. Recruiting waits for a person.

Skills it runs

One at a time, in roughly this order, skipping whatever you already have. The second list is for a question that needs it. Call any row by name and the researcher will not wrap the rest of the path around it.
