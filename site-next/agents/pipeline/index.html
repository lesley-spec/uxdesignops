Agents

Design thinking

Walks a project from Empathize to Test. It calls the phase skill, shows the work, and waits at each gate.

Ready

Get started

The easier start is the UX designer. Install once, then paste a prompt.

You can join mid-pipeline: “We already have a one-pager and UX-1234. Jump to Ideate.”

Overview

Call design-thinking-ux when you want the whole pipeline. If you only want research or only a screen, use those doors instead. This one is for the project.

Usage

Use it when

You have a flow, a hunch, or a ticket, and you are willing to stop at each decision.

Use another door when

You already know it is a research question, or you already know it is a screen. Those agents are narrower on purpose.

Anatomy

1

Intake

What you are working on, Brand or Partner, where you already are, and what you already have.

2

One phase

It reads that phase’s skill and does the work in the same chat.

3

The gate

Problem worth solving, publish, chosen direction, or recruit. It updates the board and waits.

Skills it runs

Name design-thinking-ux for the whole walk. Name a skill below when you already know the phase. Empathize is the researcher.

Empathize

This phase calls the UX researcher. The skills for it are on that agent. Design thinking runs one at a time, then waits at the gate.
