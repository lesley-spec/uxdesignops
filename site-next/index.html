UX DesignOps

What to expect

The pack has 41 skills. Most of them sit in two places: UX research, which finds out what we know, and UX design, which shapes and checks the work. A small design ops group runs the pipeline between them.

21 UX research skills Empathize and Define
14 UX design skills Ideate, Prototype and Test
6 UX design ops skills Across every phase

Ask in plain words

Describe the problem. You never need a skill name to start.

Each skill says what it needs

It asks once for what is missing, then shows its working.

A person decides at each gate

Nothing is published, recruited or launched without a yes.

Get started

  1. 1

    Install the pack once

    Paste this into your tool. It installs the whole pack for the project and for you.

    Prompt
    use ux-install-all-skills

    How to install it on Cursor, Claude, Figma and Magic Patterns →

  2. 2

    Say what you are working on

    Call the agent, then the question, in plain words.

    UX designer
    use ux-designer. Brand. Christine’s welcome header doesn’t say what to do with 35 new applications. I have a screenshot of the current screen and no working file yet.
    UX researcher
    use ux-research. What do we already know about how brand operators review new partner applications, and what would we still need to learn?
    Design thinking
    use design-thinking-ux. This is a new project. Partner. I only have a hunch. No research yet.
  3. 3

    Review before anything goes out

    The skill asks once for what it needs, shows its working, and stops at the gate. You confirm, edit or reject.
