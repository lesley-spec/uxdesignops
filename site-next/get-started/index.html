A Cursor admin can install the pack for the whole team. In the dashboard, open Plugins and MCPs, choose Add Marketplace, then Import from Repo, and paste https://github.com/lesley-spec/uxdesignops. Turn on Auto Refresh and set the impact-ux plugin to Required. That import is limited to admins.
