An agent is a package of these. Call the agent and it picks the skill. Call a skill when you already know which job you want.

Orchestrators

These skills run other skills in order. Call one when you want the whole job. Each one is also the skill behind an agent. The lists below are the skills they call, and you can still name any of them yourself.
