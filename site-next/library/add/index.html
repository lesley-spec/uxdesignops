Library

Add to the library

Add a prototype, Figma file, or research note to the UX context library. You paste it into Cursor; the agent does the filing.

Before you start

Write access

You need write access to ImpactInc/impact-ux-context-library on GitHub. If you cannot open the repo, ask for access before you start.

Cursor

Install Cursor and sign in to GitHub from inside it. Any AI coding assistant that can open a folder works the same way.

The link

Have the Figma URL, preview URL, or document link ready. Link to the source. Do not paste its contents.

Steps

  1. Clone the repo once: git clone https://github.com/ImpactInc/impact-ux-context-library.git, then open the folder in Cursor.
  2. Open a new chat in Cursor and paste one of the templates below. Replace the bracketed parts.
  3. The agent files the entry on its own branch and opens a pull request. Check the summary it gives you.
  4. A library reviewer checks the pull request and merges it. Merging is what updates the library.

After you add it

Nothing shows on the website, in Confluence, or in Ask until someone who knows the topic confirms it. Entries you add are saved as unpublished, so they will not appear there by accident.

Do not paste the full text of a research report, public Help Center pages, or customer data. Link to them instead.

Questions about the process go to the UX library owner. Background for the people maintaining the library is in the contributor guide.
