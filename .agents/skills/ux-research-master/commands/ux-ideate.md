Give me a few directions to explore for **$ARGUMENTS**.

Start from the framing we already have — one-pager, PRD, epic, tickets or
notes — and seed genuinely different approaches, not three versions of one
idea. Say what each one assumes and what it would cost to be wrong.

## How to run this

Read `.agents/skills/ideate/SKILL.md` and run its workflow in this chat
(fallbacks: `.claude/skills/ideate/`, `.cursor/skills/ideate/`,
`~/.claude/skills/ideate/`). Do not paraphrase the skill from memory.
If the output is heading for on-brand mocks, read `design-system` first.

Standing rules: label Verified vs AI interpretation · never invent a metric,
quote or participant · Jira, Confluence, Outset and Pendo stay draft-only
until a human confirms · never launch recruitment or publish a guide to live
traffic · if a connector this needs is not authorised, say which, say what
the answer loses, and run the rest.
