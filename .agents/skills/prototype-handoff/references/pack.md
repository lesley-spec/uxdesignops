# Prototype handoff pack

## Minimum links

- Chosen mock / Figma (or FigJam if that is the fidelity)
- One-pager or PRD **or** explicit “notes-only Ideate” caveat
- UX epic (when it exists)
- Latest `ux-critique` summary (inline OK)

## Decision hygiene

- Exactly **one** primary direction
- Rejected alternatives: one line each (why not)
- Tie “why” to JTBD or success criteria from framing — not taste alone

## Residual risk

If Critical items remain, handoff Status stays DRAFT until designer writes acceptance, e.g.  
`Residual risk accepted: empty-state copy deferred to Prototype — [initials/date]`.
