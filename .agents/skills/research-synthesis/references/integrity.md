# Integrity — cross-source synthesis

1. **High confidence** only with ≥2 **independent** sources (different
   populations, not the same people reached twice).
2. Every claim carries source, link, date and sample.
3. Contradictions are published, never averaged. Say what would settle them.
4. Frequency and importance are separate columns.
5. Stated sources (Dovetail, Outset, NPS, Freshdesk) and behavioural sources
   (PostHog, Pendo) are labelled as such, so the say/do gap stays visible.
6. Discarded matches are listed, so the reader can see what was filtered and
   disagree with the filter.
7. Language bounded by sample: counts below n≈30, percentages only on quant.
8. Brand and Partner themes stay separate.
9. Designer owns "problem worth solving". The skill triangulates; a person decides.
