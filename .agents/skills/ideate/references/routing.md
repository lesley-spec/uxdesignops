# Tool routing (Ideate)

| Intent | Prefer | Notes |
|---|---|---|
| Fast diverge, stickies / Crazy-8s | **FigJam** or **Claude** | No DS tokens required |
| Wireframes / structure | **Claude** or **Cursor** | Label low-fi / not DS |
| On-brand mockups | **Figma Make** or **Cursor** + `design-system` | Styleguide-aware |
| Visual variations | **Figma agent** or **Google Stitch** | Only after ideation brief exists |
| Critique / coverage | Any harness + **`ux-critique`** | Required before handoff |

Ask the designer; do not force a single tool. Recommend based on fidelity choice.
