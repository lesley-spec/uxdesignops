# Research report map

Primary file: `research-agent/docs/research/latest.json`

Useful keys:

| Key | Use |
|---|---|
| `generated_at` | Freshness |
| `period` | Lookback window |
| `source_counts` / `sources` | Coverage honesty |
| `summary` | Counts, severity, by_audience |
| `posthog_dropoffs` | Ranked issues + links + `research_context` |

HTML twin: `research-agent/docs/research/reports/YYYY-MM-DD.html` for human reading.
